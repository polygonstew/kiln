# Architecture

```
server.py            stdlib HTTP server: static files, ComfyUI driver + websocket progress,
                     cloud image engine, file manager API, projects, export writer
static/index.html    shell: top bar (wordmark, tabs, style chip, asset-folder chip, job tray)
static/kiln.css      the whole design system (tokens at :root)
static/js/
  app.js             boot, tabs (1–6), cross-tab routing of events
  core.js            DOM helper h(), api(), event bus (emit/on), palettes + HARDWARE limits,
                     image ops, quantise (k-means), dithering, the sprite pipeline pixelize()
  text.js / fonts.js bitmap text renderer + BMFont builder; fonts.js is generated by
                     tools/bdf2js.py from vendor/fonts/*.bdf
  queue.js           generation queue + top-bar tray, learns seconds/step for estimates
  style.js           style bible (kiln/style.json in the asset folder)
  files.js           Files tab + saveFiles() used by every exporter
  player.js          animation previewer (Player), loadActor() for manifest folders
  forge.js           Forge tab (new thing / making frames for an actor)
  animate.js         Animate tab
  motion.js          motion generators (one frame → animation)
  slicer.js          sheet slicer modal (grid or figure detection)
  scenes.js          Scenes tab; procgen.js = layer generators + presets
  hud.js             HUD tab
  stage.js           Stage tab
  icons.js           16px line icons
tools/bdf2js.py      BDF → fonts.js converter
vendor/fonts/        Spleen + Tom Thumb BDFs and licences
library/             (gitignored) settings.json, default asset folder, cloud images
```

## Event bus (core.js `emit`/`on`)

| Event | From → to | Payload |
|---|---|---|
| `root` | files → style, files tree | new asset folder path |
| `style` | style → forge, hud | STYLE object |
| `saved` | saveFiles → files, scenes, stage | folder written |
| `job-done` | queue → forge | job |
| `to-animate` | forge → animate | `{mode:'new'|'frame', img, pal, name, identity?, forName?}` |
| `forge-for` | animate → forge | identity (see CONSISTENCY.md) |
| `open-actor` / `slice-sheet` | files → animate | path |
| `open-scene` / `scene-layer` | files → scenes | path |
| `forge-image` / `use-palette` | files → forge | path / `{name, colors}` |
| `tab` | anyone → app | tab id |

Modules register listeners at import time and queue requests until mounted. `app.js` switches
to the handling tab for the routed events.

## Server API

| Method | Path | Notes |
|---|---|---|
| GET | `/api/status` | ComfyUI health, which engines have their models, queue length, cloud `{ok,left}` |
| POST | `/api/gen` | `{engine: sprite|scene|painted|cloud, prompt, neg, w, h, batch, steps, seed, init?, denoise?, engine_hint?}` → `{id, seed}` |
| GET | `/api/job?id=` | `{state: queued|running|done|error, step, steps, images[], err, ahead}` |
| POST | `/api/cancel` | `{id}` |
| GET | `/api/view?…` | proxies ComfyUI `/view` |
| GET | `/api/cloudimg?f=` | cloud results in `library/cloud/` |
| GET | `/api/fs?path=` | folder listing + role badges (`role`, `ok`, `info`, `help`) |
| POST | `/api/fs` | `{op: mkdir|rename|trash|root|scaffold|bookmark, …}`. Trash = move to `<root>/.trash/` |
| GET | `/api/fs/raw?path=` | any file under `$HOME` |
| GET | `/api/settings` | root, bookmarks, layout descriptions, home |
| GET | `/api/godot?path=` | nearest parent folder with `project.godot` (for `res://` paths) |
| GET/POST | `/api/project` | Kiln source projects in `<root>/kiln/<id>.json` |
| GET | `/api/projects` | list of them (`meta.kind`: actor | scene | hud | style) |
| POST | `/api/export` | `{dest (relative to root, or absolute under $HOME), files:[{name, b64|text}]}` |

All file paths are confined to `$HOME`.

## Local generation workflow (server.build)

`CheckpointLoaderSimple → LoraLoader(s) → CLIPTextEncode ×2 → EmptyLatentImage | (LoadImage →
ImageScale → VAEEncode [→ RepeatLatentBatch]) → KSampler (lcm/sgm_uniform) → VAEDecode → SaveImage(kiln/k)`.
Progress comes from ComfyUI's websocket (minimal client in `ws_listen`).
